# One-shot install for machines with no GPU (or for users who want a
# small CPU-only install). Pulls CPU torch from PyTorch's
# dedicated CPU wheel index - about half the download size of the
# default torch wheel, which bundles CUDA libraries even on CPU-only
# machines.
--extra-index-url https://download.pytorch.org/whl/cpu
-r requirements-all.txt
torch>=2.5
